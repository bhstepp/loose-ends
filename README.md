# Loose Ends

A tap-to-clear ribbon puzzle for iPhone. Everything runs in the browser: no server, no accounts.

**Play:** open this site's GitHub Pages address in Safari, then Share → Add to Home Screen for a full-screen app that also works offline.

Progress (level, buttons, fabrics, streaks, and the board you're partway through) is saved automatically on each device.

Files: `index.html` is the whole game. `sw.js` and `manifest.webmanifest` make it installable and offline-capable.
